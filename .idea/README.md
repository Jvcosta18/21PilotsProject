## 🎵 Twenty One Pilots — Stay Alive

Um site interativo que celebra a trilogia de álbuns da banda **Twenty One Pilots**, apresentando as "eras" musicais com design moderno e imersivo.

### 📚 Sobre o Projeto

Este projeto é um tributo visual à evolução musical da Twenty One Pilots, explorando seus principais álbuns da trilogia com curiosidades, timeline de eventos e um design que captura a essência artística de cada era.

### ✨ Características

- **Design Responsivo**: Interface adaptável para diferentes tamanhos de tela
- **Animações Fluidas**: Transições suaves e efeitos visuais imersivos
- **Paleta de Cores Temática**: Cores vibrantes que representam cada era musical
- **Navegação Intuitiva**: Menu lateral com dots de navegação e scroll suave
- **Galeria de Imagens**: Capas de álbuns e fotos dos integrantes
- **Tipografia Premium**: Fontes customizadas (Bebas Neue, Space Mono, DM Serif Display)

### 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (Grid, Flexbox, Animações)
- JavaScript

### 📖 Conteúdo

Apresenta informações sobre as principais eras musicais da banda, incluindo detalhes dos álbuns, datas importantes e curiosidades.
